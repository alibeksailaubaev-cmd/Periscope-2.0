# Санация линий поения — учёт по графику санитарного разрыва

Инструменты для АО «Усть-Каменогорская птицефабрика»: из месячного графика
санитарного разрыва (`.xlsx`) выбираются птичники и дни, в которые проводятся
работы по санации линий поения и обработке помещений, чтобы дальше считать
расход и стоимость дезсредств.

## Что уже сделано

`src/parse_schedule.py` разбирает лист графика и выдаёт по каждому птичнику
(цех + этаж) список операций с датами — в консоль, JSON или CSV.

```bash
pip install openpyxl

python3 src/parse_schedule.py data/grafik-sanrazryva-2026-09.xlsx
python3 src/parse_schedule.py data/grafik-sanrazryva-2026-09.xlsx \
    --csv out/sanaciya.csv --json out/sanaciya.json --quiet
```

## Какие отметки берём из графика

Этапы санации линии поения:

| Отметка в графике | Что это | Этап |
|---|---|---|
| `ОС/ОЧН` | освобождение / очистка ночь | санация 1 |
| `МС` | мойка сутки | санация 2 |
| `ПР/Р` | приёмка птичника + мойка | санация 3 |
| `ПДГ` | подготовка | санация 4 |

Дополнительно учитываются обработки:

| Отметка | Берём | Что это |
|---|---|---|
| `Р\ДС` | только `ДС` | дезинсекция |
| `ДЗ/ЗН`, `ДЗ/ПН`, `ЗО/ДЗ/ГГ`, `ДЗ/ГГ`, `ДЗ/ГФ`, `ДЗ/ГФ/ОД` | только `ДЗ` | дезинфекция |
| `ГГ` | `ГГ` | газация глутаркой |
| `ГФ` | `ГФ` | газация формалином |
| `ОД` | `ОД` | обработка дорог |

Не учитываются: `Р` (ремонт), `ЗН`/`ЗО` (засыпка), `ЗС` (заселение),
`СО` (септик-обработка), `П`/`ПН` (побелка), `Ш` (шахта).

Ячейка может содержать несколько отметок через `/` или `\` — они разбираются
по отдельности, поэтому `ПДГ/ОД` даёт и подготовку, и обработку дорог в один
день.

## Структура графика

* Лист — один месяц, шапка со сроками в строке 7, дни месяца в колонках `C`…`AF`.
* Строки 8–129 — птичники: колонка `A` цех, `B` этаж (дублируются справа в `AG`/`AH`).
* Названия цехов в файле стоят в объединённой ячейке в середине блока, а не на
  весь блок, поэтому границы блоков заданы в `SHOP_BLOCKS` в скрипте.
* Ниже строки 130 — расшифровка обозначений.

## Данные

* `data/grafik-sanrazryva-2026-09.xlsx` — график санитарного разрыва, сентябрь 2026.
* `data/dezsredstva.csv` — прайс дезсредств (43 позиции), перенесён с бумажного
  списка. У позиций 2, 25, 34 цены нет; по позиции 26 (ГиперДез) печатная цена
  зачёркнута и от руки указано `1020` — нужно уточнить.

# Меловой остров

3D-игра на выживание за динозавра для телефона. Работает прямо в браузере,
без установки: Three.js, чистый JavaScript, без сборщиков.

## Что есть в игре

- **Три вида на выбор**: дакотараптор (быстрый хищник), трицератопс (травоядный танк),
  тираннозавр (высший хищник). Все из фауны формации Хелл-Крик, 66 млн лет назад.
- **Рост**: вы вылупляетесь детёнышем и растёте, пока сыты и не хотите пить.
  Взрослый динозавр больше, сильнее и живучее.
- **Выживание**: здоровье, сытость, вода и силы. Хищники едят туши, травоядные едят папоротники.
  Пить можно из озёр внутри острова, морская вода солёная.
- **Живой остров**: стада струтиомимов, трицератопсов и анкилозавров, стаи дакотарапторов,
  тираннозавры, кетцалькоатли в небе. Травоядные убегают или защищаются, хищники охотятся стаей.
- **Исследование**: 9 мест, которые можно открыть, туман на карте и журнал с фактами о видах.
- **Смена дня и ночи**, вулкан с лавой, облака, ветер в листве.
- Сохранение прогресса в браузере. Открытые места и изученные виды остаются после гибели.

## Управление

| Телефон | Компьютер | Действие |
|---|---|---|
| левая половина экрана | WASD | движение |
| правая половина экрана | стрелки ← →, колесо | камера |
| «Бег» (держать) | Shift | бег, тратит силы |
| «Атака» | пробел | укус или удар |
| «Есть» / «Пить» (держать) | E | появляется рядом с едой и водой |
| «Рёв» | R | отпугивает мелких животных |
| «Лечь» | C | отдых: быстрее лечит, ускоряет время |
| карта | M | карта и журнал |

## Как запустить

Нужен любой статический веб-сервер (модули ES не открываются через `file://`):

```
npx http-server dino
```

Для публикации бесплатно подходит GitHub Pages: Settings → Pages → ветка и папка `/dino`
(или корень, если перенести игру в отдельный репозиторий).

## Устройство кода

```
index.html        разметка интерфейса
style.css         стили
src/main.js       игровой цикл, камера, меню, сохранения
src/terrain.js    форма острова (без three.js — пригодится серверу для мультиплеера)
src/world.js      рельеф, вода, небо, растения, достопримечательности
src/dinos.js      виды, процедурные модели и анимация
src/ecosystem.js  ИИ животных
src/player.js     игрок: показатели, рост, действия
src/creature.js   общая физика передвижения
src/input.js      сенсорный джойстик и клавиатура
src/audio.js      синтез звуков и загрузка своих файлов из sounds/
src/hud.js        показатели, мини-карта, журнал
```

## Что дальше

- Мультиплеер: комнаты по коду на WebSocket-сервере. Мир детерминирован (фиксированный сид),
  поэтому серверу достаточно синхронизировать игроков и животных.
- Больше видов, гнёзда и размножение, погода.

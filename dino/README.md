# Меловой остров

3D-игра на выживание за динозавра для телефона. Работает прямо в браузере,
без установки: Three.js, чистый JavaScript, без сборщиков.

## Что есть в игре

Хоррор-выживание от первого лица. Ваш вертолёт разбился на острове, где динозавры не вымерли.

- **Цель**: найти 5 частей рации (ящики с мигающей лампой у достопримечательностей),
  вызвать помощь на Мысе заката и продержаться 90 секунд до прилёта вертолёта.
- **Скрытность**: хищники видят (конус обзора, дальность зависит от укрытия и темноты) и слышат
  (бег слышно метров за 40). Присядьте в траве или папоротниках, и вас почти не видно.
  Фонарик ночью выдаёт вас.
- **Хищники**: крадутся на звук, охотятся стаей, обыскивают место, где потеряли вас.
  Глаза светятся в темноте, шаги тираннозавра трясут землю.
- **Выживание**: здоровье, сытость, вода и силы. Еда — молодые побеги папоротника,
  вода — озёра внутри острова (морская солёная).
- **Мир**: фототекстуры рельефа, атмосферное небо, вода с отражениями и пеной, густая трава,
  смена дня и ночи, туман, журнал мест и видов, карта с туманом войны.

## Управление

| Телефон | Компьютер | Действие |
|---|---|---|
| левая половина экрана | WASD | идти |
| правая половина экрана | мышь (зажать) | осматриваться |
| «Бег» (держать) | Shift | бег, тратит силы и шумит |
| «Присесть» | C | прятаться, тише и незаметнее |
| «Фонарь» | F | свет ночью, но вас видно |
| «Взять» / «Есть» / «Пить» (держать) | E | появляется рядом с предметом, едой, водой |
| карта | M | карта и журнал |

## Как запустить

Нужен любой статический веб-сервер (модули ES не открываются через `file://`):

```
npx http-server dino
```

Для публикации бесплатно подходит GitHub Pages: Settings → Pages → ветка и папка `/dino`
(или корень, если перенести игру в отдельный репозиторий).

## Устройство кода

```
index.html        разметка интерфейса
style.css         стили
src/main.js       игровой цикл, камера, меню, сохранения
src/terrain.js    форма острова (без three.js — пригодится серверу для мультиплеера)
src/world.js      рельеф, вода, небо, растения, достопримечательности
src/dinos.js      виды, процедурные модели, анимация, светящиеся глаза
src/ecosystem.js  ИИ животных: зрение, слух, подкрадывание, охота, поиск
src/player.js     человек: движение, скрытность, показатели, действия
src/creature.js   общая физика передвижения
src/input.js      сенсорный джойстик и клавиатура
src/audio.js      синтез звуков и загрузка своих файлов из sounds/
src/hud.js        показатели, мини-карта, журнал
```

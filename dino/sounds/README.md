# Свои звуки

Положите сюда аудиофайлы (mp3, ogg или wav) и перечислите их в `sounds.json`:

```json
{
  "roar-rex": "roar-rex.mp3",
  "roar-raptor": "roar-raptor.mp3",
  "roar-trike": "roar-trike.mp3",
  "bite": "bite.mp3"
}
```

Ключи, которые понимает игра: `roar-raptor`, `roar-trike`, `roar-rex`, `roar-strut`, `roar-anky`, `bite`.
Для всего, чего нет в списке, игра синтезирует звук сама.

Используйте только звуки, на которые у вас есть права: записанные самостоятельно
или с лицензией, разрешающей такое использование (например, CC0 с freesound.org).

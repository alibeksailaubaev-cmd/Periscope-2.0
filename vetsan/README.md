# Акт мойки ЗПП — мобильное приложение + импорт в Excel Online

`index.html` — самодостаточное приложение (один файл, без сборки и интернета).
`office-script-import.ts` — скрипт для кнопки **«Автоматизация»** в Excel в браузере.

Данные книги: форма Ф-ВС-29, листы «Акт мойки», «Динамика», «Хронометраж»,
«Журнал несоответствий», «Архив несоответствий», «Статистика перемывок».

## Способ 1 — письмом, книгу никто не открывает

Врач заполняет акт в телефоне, нажимает «Отправить в акт» и отправляет готовое
письмо. Дальше книга заполняется сама, обычно в течение минуты.

Важно, чего здесь **нет**: телефон ничего не принимает и ничем не управляет,
входящих подключений не существует, компьютер может быть выключен. Письмо
уходит обычной корпоративной почтой, а Power Automate работает на серверах
Microsoft и читает ящик изнутри облака — той же учётной записью, под которой
сотрудник и так открывает Outlook. Ни портов, ни белых списков, ни прав
администратора.

### Настройка потока (один раз, ~10 минут)

Сначала — Office Script по инструкции ниже (Способ 2, шаги 1–5): поток
запускает именно его.

1. Открыть `make.powerautomate.com` под рабочей учётной записью.
2. «Создать» → «Автоматизированный облачный поток», имя — «Акты мойки ЗПП».
3. Триггер: **«При поступлении нового сообщения электронной почты (V3)»**
   (Office 365 Outlook).
4. В параметрах триггера: папка «Входящие», фильтр темы — **`Акт мойки ЗПП`**.
   Приложение ставит эту тему само.
5. Действие: **Excel Online (Business) → «Выполнить скрипт»**.
   - Расположение — сайт группы Teams, где лежит книга;
   - Библиотека документов — «Документы»;
   - Файл — книга акта;
   - Скрипт — «Импорт акта мойки»;
   - Параметр **`письмо`** — динамическое содержимое **«Тело»**.
6. Необязательно, но удобно: действие **«Ответить на сообщение (V3)»**, в текст
   вставить динамическое содержимое **`result`** скрипта. Врач получит на
   телефон подтверждение: «Акт АМ-… принят. Позиций: 131. Несоответствий: 5.
   Итоговый балл: 9,93».
7. Сохранить и проверить: отправить акт из приложения, через минуту открыть
   книгу и сверить листы.

Тело письма — одна строка JSON. Скрипт сам снимает HTML-обёртку, склеивает
перенесённые по ширине строки и разбирает пакет.

### Ограничение

Длина ссылки `mailto` — около 2000 символов, это примерно 15 несоответствий за
акт. Приложение считает длину и предупреждает заранее; при большем объёме
работает Способ 2. По архиву несоответствий средняя проверка даёт 4–5 пунктов,
так что предел достигается редко.

## Способ 2 — Office Script вручную

Запасной путь: тот же скрипт, но пакет переносится через буфер обмена, а книгу
нужно открыть. Годится, когда несоответствий слишком много для письма или пока
поток не настроен.

### Настройка (один раз, 5 минут)

1. Откройте книгу в браузере (Excel Online на SharePoint).
2. Создайте лист с именем **`Импорт`** — это буфер на одну ячейку.
   Его можно скрыть: правой кнопкой по ярлыку → «Скрыть».
3. Вкладка **«Автоматизация»** → **«Новый скрипт»**.
4. Удалите содержимое редактора, вставьте код из `office-script-import.ts`.
5. Переименуйте скрипт в **«Импорт акта мойки»** и сохраните.

### Ежедневная работа

1. В приложении заполнить акт → **«Отправить в Excel»** → **«Копировать»**.
2. В книге: лист `Импорт`, ячейка `A1`, вставить (Ctrl+V).
3. **«Автоматизация» → «Импорт акта мойки» → «Выполнить»**.

Что делает скрипт:

| Лист | Действие |
|---|---|
| Акт мойки | `C4` — дата проверки; всем 131 позиции ставит 10 баллов, затем проставляет фактические баллы, описания несоответствий (`F`), ответственных (`G`) и отметку МДС (`C`) |
| Хронометраж | находит строку по дате (или добавляет новую), пишет начало `C`, окончание `F`, врача `J` |
| Динамика | находит строку по дате, пишет итоговый балл `C` |
| Архив несоответствий | дописывает строки несоответствий после последней заполненной |
| Журнал несоответствий | **не трогает** — лист заполняется своими формулами `MATCH/INDEX` по столбцу `J` листа «Акт мойки» |

Средние баллы по участкам и зонам (`E9`, `E153:E156`) остаются формулами книги
и пересчитываются сами.

### Защита файла

Скрипт пишет только значения в `C`, `D`, `F`, `G` листа «Акт мойки» и дописывает
строки в конец «Архива». Формулы (`E`, «Журнал несоответствий», «Статистика
перемывок») он не трогает.

Перед записью выполняется сверка: каждая позиция из пакета проверяется по
наименованию в колонке `B`. Если строки сместились (кто-то вставил строку в
бланк), позиция находится по названию заново. Если позиции больше нет вовсе —
скрипт прекращает работу **до первой записи** и сообщает, что именно не найдено;
книга остаётся нетронутой, полузаполненного акта не бывает.

Запись идёт непрерывными блоками строк (9–14, 16–26, 28–52, 54–58 …), поэтому
объединённые строки-заголовки участков не задеваются.

### Почему пакет такой короткий

По умолчанию все позиции — 10 баллов, поэтому передаются только отклонения:
`[11,8,"органика",1,"Петров И.И.","2026-08-22"]` — строка акта, балл, описание,
отметка МДС, ответственный, срок. Ключи латинские, потому что в ссылке письма
каждый кириллический символ занимает девять символов. Типичный акт — 400–900
символов.

Поле `rows` содержит структуру бланка («9-14,16-26,28-52,…»). Скрипт строит
такую же строку по книге и сверяет: так проверяется, что строки не сместились.

### Проверка перед внедрением

Прогнать на копии книги: в Teams → «Файлы» → правой кнопкой по файлу →
«Создать копию», настроить скрипт на копии, загрузить один акт и сверить
листы. Только после этого подключать скрипт к рабочему файлу.

## Способ 3 — вставка вручную, без скрипта

Если «Автоматизация» окажется отключена политикой арендатора: открыть в
приложении «Полный JSON», данные листа «Журнал несоответствий» перенести
руками — их обычно единицы. Баллы придётся проставлять в книге вручную.

## Чего сознательно нет

Триггер «При получении HTTP-запроса» дал бы отправку одним нажатием, без
почтового клиента. Он не используется: коннектор Request — премиальный
(отдельная лицензия Power Automate), а страница артефакта не может делать
сетевые запросы, то есть приложение пришлось бы вынести на свой хостинг.
Почтовый путь даёт тот же результат на базовой лицензии.

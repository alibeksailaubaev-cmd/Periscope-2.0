# Video Studio — генератор видео по промпту

Локальная студия, которая по теме/промпту сама:

1. пишет сценарий, разбитый на сцены (**Промпты**);
2. озвучивает каждую сцену голосом (**Озвучка**);
3. рисует картинку под каждую сцену (**Кадры**);
4. собирает всё в один mp4 с эффектом Ken Burns (плавный зум) через ffmpeg (**Видео**);
5. отдельно генерирует обложку.

Это отдельный проект — не связан с фронтендом Periscope-клона в корне репозитория.

## Два режима генерации

### 1. Платный, качественный (рекомендуется) — через OpenAI

Один API-ключ покрывает сразу сценарий, голос и картинки:

- **Сценарий** — Chat Completions (`gpt-4o-mini`);
- **Озвучка** — OpenAI TTS (`tts-1`);
- **Картинки** — `dall-e-3`.

Стоимость — центы/десятки центов за ролик (Long на 12 сцен: ~$0.5 за картинки + копейки за текст и голос), а не бесплатно, зато результат стабильный и качественный — как у профессиональных YouTube-каналов на автопилоте.

**Настройка:**
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com), привяжите карту и пополните баланс (достаточно $5).
2. Создайте ключ: **API keys → Create new secret key**, скопируйте (начинается с `sk-...`).
3. В папке `video-studio` скопируйте `.env.example` в `.env` и вставьте ключ:
   ```
   OPENAI_API_KEY=sk-ваш-ключ
   ```
4. Перезапустите `npm start` — в шапке дашборда появится «OpenAI (платно)».

### 2. Бесплатный, без ключей (по умолчанию, без `.env`)

- **Текст** — [Pollinations text API](https://pollinations.ai);
- **Озвучка** — бесплатный сервис Microsoft Edge "Read Aloud" (лицензия CC BY-NC-SA — только некоммерческое использование);
- **Картинки** — [Pollinations image API](https://pollinations.ai).

Это общедоступные сервисы без SLA: они периодически меняют условия, вводят лимиты или временно недоступны — качество и стабильность не сравнить с платным режимом. Именно поэтому в каждом провайдере есть **офлайн-заглушка**: если реальный запрос не удался, шаг всё равно выполняется — подставляется локально сгенерированный текст/тишина/картинка-плейсхолдер, чтобы конвейер не падал целиком, а всегда доходил до готового видеофайла. Причина подмены всегда видна в журнале задания.

Если задан `OPENAI_API_KEY`, каждый шаг сначала пробует OpenAI, при ошибке — бесплатный API, при ошибке — заглушку. Без ключа — сразу бесплатный API → заглушка.

Принудительно включить только заглушки (без единого сетевого запроса) — переменная окружения:

```bash
OFFLINE_MODE=1 npm start
```

## Запуск

```bash
cd video-studio
npm install
npm start
```

Откройте `http://localhost:4100`.

## Как это устроено

```
video-studio/
  server.js              Express: REST API + раздача дашборда + SSE-поток логов
  src/
    config.js             пресеты форматов (Long/Short), визуальные стили
    store.js               job.json на диск, один каталог на задание
    queue.js                очередь на одного воркера (как в реальном GPU-пайплайне)
    pipeline.js             сам конвейер: сценарий → озвучка → кадры → монтаж → обложка
    ffmpegTools.js           обёртки над ffmpeg/ffprobe (Ken Burns, конкатенация, длительность)
    logger.js                 журнал задания (файл + живая трансляция по SSE)
    providers/
      openai.js                  OpenAI: сценарий (chat) + голос (tts-1) + картинки (dall-e-3)
      script.js                  OpenAI → Pollinations text → офлайн-заглушка сценария
      tts.js                     OpenAI → Edge TTS → офлайн-заглушка (тишина)
      image.js                   OpenAI → Pollinations image → офлайн-заглушка (SVG-плейсхолдер)
  public/                  дашборд (обычные HTML/CSS/JS, без сборщиков)
  data/jobs/<id>/          файлы задания: audio/, images/, clips/, output/, job.json, log.txt
```

### Очередь и пауза/продолжение

Одновременно рендерится только одно задание — как на настоящем конвейере с ограниченным
API-лимитом. Остановка (`Остановить`) не убивает процесс на середине шага — конвейер
проверяет флаг паузы между сценами и аккуратно останавливается, сохранив уже готовые
файлы. `Продолжить` просто перезапускает тот же job: любой шаг, для которого файл уже
существует на диске, пропускается, поэтому дорендер идёт только оставшихся сцен.

### Форматы

- **Long** — 12 сцен, ~70 слов на сцену, горизонтальное 1280×720 (документалка).
- **Short** — 5 сцен, ~18 слов на сцену, вертикальное 720×1280.

Толкатели «Историческая точность» / «Профиль материалов» добавляют соответствующие
инструкции в системный промпт сценария (просьба опираться на факты и известные источники),
а не проверяют факты постфактум — для реальной проверки фактов нужен отдельный шаг, которого
здесь нет.

## Известные ограничения первой версии

- Один голос по умолчанию (`ru-RU-SvetlanaNeural`) — переключение голоса через UI не сделано.
- Нет ретраев с backoff при рейт-лимитах бесплатных API — при неудаче сразу используется заглушка.
- Обложка и кадры сцен генерируются независимо друг от друга, повторного использования
  одной картинки на несколько сцен (как экономия промптов) нет.
- Проверено под Node.js 18+.

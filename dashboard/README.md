# Executive Dashboard — биобезопасность и нагрузка персонала

Интерактивный дашборд для обоснования расширения штата отдела биобезопасности.

## Файлы

- `BiosecurityExecutiveDashboard.jsx` — компонент в одном файле (React + Framer Motion + Highcharts + lucide-react + Tailwind). Готов к вставке в Claude Artifact или в любой React/Vite/Next проект.
- `dashboard.html` — автономная сборка (все библиотеки внутри, без CDN и внешних запросов). Открывается двойным кликом.

## Зависимости для проекта

```bash
npm i react react-dom framer-motion highcharts highcharts-react-official lucide-react
```
Tailwind CSS должен быть подключён в проекте (в Claude Artifact он есть по умолчанию).

## Модель данных

Все показатели вычисляются из единой таблицы `TASKS` (20 направлений), поэтому цифры
всегда согласованы между собой:

| Показатель | Значение | Откуда |
|---|---|---|
| Объём задач | 148 нормо-часов/нед | сумма `hours` |
| Ёмкость 2 сотрудников | 80 ч/нед | `STAFF × HOURS_PER_STAFF` |
| Загрузка | 185 % | 148 / 80 |
| Покрытие внешнего контура | 55 % | 50 из 91 ч по внешнему контуру |
| Дефицит штата | +2 единицы | ⌈148 / 40⌉ − 2 |

Чтобы изменить цифры, правьте только массив `TASKS` и константы `STAFF` / `HOURS_PER_STAFF`
— KPI, график, виджет перегрузки и модальное окно пересчитаются сами.

## Интерактив

- Переключатель периода: День / Неделя / Месяц — перестраивает Highcharts и KPI.
- Клик по внешнему контуру: каскадный список 20 направлений по трём группам + разбивка на графике.
- Клик по внутреннему контуру: подсветка красным, виджет перегрузки, список «проваливается / реально закрывают» + столбцы перегрузки на графике.
- Постоянная анимация: задачи слетаются с внешнего контура и садятся на двух сотрудников, стопка задач над ними растёт.
- Кнопка «Аргументация для руководства» — модальное окно с четырьмя тезисами.
- Переключатель тёмной и светлой темы.

# Сводный дэшборд AITAS UKPF — фирменное оформление

Готовый файл: **`dashboard.html`** — один самодостаточный HTML. Открывается двойным
кликом в браузере, ничего устанавливать не нужно. Внутри — три вкладки (Цех инкубации,
ЗПП, Бройлерное производство), каждая со своей логикой расчётов; она не менялась,
переработаны только оформление, анимации и удобство подготовки отчётов.

## Что изменилось в дизайне

**Корпоративный стиль** — песочный фон (`#e6dfc6`), фирменная бирюза (`#0e9a92`),
графитовый текст, орнаментальная колонка слева и логотип-локап `aitas ukpf`,
как на корпоративных материалах фабрики.

**Оболочка**
- шапка с логотипом, поясняющим лидом и меткой раздела;
- зона загрузки общего файла «Свод рабочих журналов МБ» с наведением, перетаскиванием
  и состоянием «загружено»; рядом — карточка статусов приёма файла по каждой вкладке
  (ожидание / передача / принято N записей / ошибка);
- вкладки — сегментированный переключатель со скользящим индикатором и точкой-статусом
  на каждой вкладке; переключение с клавиатуры `Alt+1 / Alt+2 / Alt+3`;
- липкая панель вкладок при прокрутке, полоса прогресса чтения, кнопка «наверх»;
- быстрая навигация «Разделы» — чипы разделов активной вкладки, клик прокручивает
  к нужной карточке и подсвечивает её;
- кнопка **«Скачать все слайды вкладки»** — последовательно выгружает все PNG-слайды
  активной вкладки с индикацией прогресса;
- скелетоны на время загрузки панели, всплывающие уведомления о статусах.

**Панели (внутри вкладок)**
- карточки: мягкая тень, фирменная полоса сверху, каскадное появление, подсветка при
  переходе из навигации;
- кнопки: единая система (основная / вторичная / выгрузка слайда), блик при наведении,
  «волна» по клику, кольцо фокуса, состояние «выключено»;
- KPI-плитки: цветной акцент по смыслу (норма / отклонение), анимированные счётчики
  (значения плавно «докручиваются» до нового числа), подъём при наведении;
- таблицы: липкая шапка, зебра-подсветка строк, фирменные бейджи OK / NOK / ожидание;
- модальные окна «детали дня» и «карточка корпуса»: размытие фона, плавное появление,
  закрытие по `Esc` и клику по фону;
- графики Plotly перекрашены в фирменную палитру (единый шрифт, сетка, подсказки),
  столбики «вырастают» из нуля, блок графика плавно проявляется;
- загрузчик файла: фирменный спиннер с бегущей полосой прогресса.

**Отчётность.** Экспорт слайдов работает как раньше (html2canvas, прозрачный фон,
масштаб 2×), но на время съёмки включается режим `aitas-exporting`: анимации и тени
замораживаются, декоративные элементы скрываются — PNG получается чистым.
Учтены `prefers-reduced-motion` и печать.

## Структура

```
dashboard/
  dashboard.html          собранный файл — его и открывают/рассылают
  build.py                сборка: тема + панели -> dashboard.html
  src/
    shell.html            оболочка: шапка, вкладки, навигация, экспорт (+ метка __DASH_B64_JSON__)
    theme.css             фирменная тема панелей
    theme.js              анимации панелей, тема графиков, мост с оболочкой
    panels/
      incubation.html     исходные панели (логика расчётов не меняется)
      zpp.html
      broiler.html
```

## Пересборка

```bash
python3 dashboard/build.py
```

Скрипт подмешивает `theme.css` и `theme.js` в конец каждой панели, кодирует панели в
base64 и подставляет их в оболочку. Правки вносите в `src/`, а не в `dashboard.html` —
он перезаписывается при каждой сборке.

## Замечания

- Панели подключают Plotly, SheetJS, JSZip и html2canvas с CDN — для работы графиков
  нужен интернет (как и в исходной версии).
- Логотип в шапке — векторный знак и надпись `aitas ukpf`; при желании его можно
  заменить на официальный файл логотипа, вставив изображение в `src/shell.html`
  (блок `.logo-lockup`) и пересобрав файл.

## Проверка перед отправкой (локальный стенд)

Панели тянут библиотеки с CDN, поэтому автоматическую проверку удобно гонять на
локальных копиях этих библиотек:

```bash
npm i playwright plotly.js-dist-min@2.27.0 xlsx@0.18.5 jszip@3.10.1 html2canvas@1.4.1
pip install openpyxl
python3 dashboard/tests/make_fixtures.py     # тестовые Excel-файлы
python3 dashboard/tests/build_stand.py       # стенд с локальными библиотеками
python3 -m http.server 8099 --directory dashboard/tests/stand &
node dashboard/tests/check.cjs                # загрузка файлов + проверка отрисовки
```

Скрипт загружает тестовые «Акт приёма мойки» и «Свод МБ» в панель и падает с
ненулевым кодом, если графики не видны, KPI не посчитаны или в консоли есть ошибки.
Каталог `dashboard/tests/stand/` в git не хранится — он пересобирается командами выше.

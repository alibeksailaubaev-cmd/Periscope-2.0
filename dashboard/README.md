# Дэшборд качества мойки и МБ смывов/воды — МПФ

Одностраничное офлайн-приложение (`mpf-dashboard.html`): открывается двойным кликом в браузере,
данные никуда не отправляются — оба Excel-файла разбираются прямо на странице.

## Что загружается

| Файл | Что берётся |
|------|-------------|
| **Акт приёма мойки** | листы «ГРАФИК ДИНАМИКИ» (баллы по дням) и «ЖУРНАЛ НАРУШЕНИЙ АРХИВ» (несоответствия по залам) |
| **Свод рабочих журналов МБ** | лист с пробами: дата отбора, точка отбора, корпус/помещение, результат, ОК/NOK |

## Фильтры свода МБ

Из общефабричного свода в дэшборд попадают только:

- **Предприятие** — ТОО «Макинская птицефабрика» (МПФ);
- **Подразделение** — содержит «инкубац» или «инкубатор»;
- **Группа материала** — «Смывы» или «Вода»;
- бахильные пробы (подгруппа материала) — исключаются;
- **Дата отбора пробы** — с 01.07.2026 (если таких проб в файле нет, показывается весь период файла с пометкой).

Применённые фильтры видны на карточке в виде чипов, а раскрывающийся блок
«Как разобран файл» показывает, сколько строк осталось после каждого шага.

## Выбор недели

Список недель строится по загруженным данным (номер недели, диапазон дат и число проб),
год берётся из самих данных. Можно выбрать неделю из списка или ввести номер вручную.

## Устойчивость к формату выгрузки

Свод выгружается из Power Apps / Power Automate, и его структура меняется от выгрузки к выгрузке.
Парсер это учитывает:

- заголовки распознаются нечётко — «Дата отбора пробы» и «Дата_отбора_пробы» равнозначны,
  регистр, неразрывные пробелы и переносы строк не мешают;
- шапка ищется по началу листа, а не берётся строго первой строкой;
- имя листа не обязано быть «Sheet1» — перебираются все листы книги;
- ячейки без атрибута `r="A1"` восстанавливаются по порядку следования;
- если данных не осталось, показывается, какой именно фильтр их отсеял и какие значения
  реально встречаются в файле.

Большие файлы читаются потоково (кусками по 8 МБ), поэтому свод на сотни тысяч строк
не упирается в лимит длины строки в браузере.

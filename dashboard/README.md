# Дэшборд контроля ТМЦ, ИЯ и сырья — АО «Усть-Каменогорская птицефабрика»

Автономный офлайн-дэшборд в корпоративном стиле **aitas ukpf**. Один файл
`dashboard/index.html` — открывается двойным кликом, работает без интернета и без
сервера. Данные никуда не передаются: разбор Excel и вся аналитика выполняются
локально в браузере.

## Что внутри

| Раздел | Назначение |
|---|---|
| **Обзор** | все записи внешнего и внутреннего контура вместе |
| **Внешний контур** | приёмка от поставщиков: брак, претензии, биобезопасность ТС |
| **Внутренний контур** | перемещения между цехами и площадками |
| **Смывы транспорта** | лабораторный контроль транспорта по сводке МБ (фоновый разбор) |
| **PEST Control** | родентицидный контроль по 12 площадкам с вводом и автосохранением |

## Дизайн-система

Повторяет фирменный стиль предприятия:

- палитра: бирюза `#00A6A9` / `#00787A`, песочный `#E4DBBF`, кремовый фон, тёплые линии `#E4DCC6`;
- вертикальная орнаментальная полоса из казахских орнаментов — 10 глифов нарисованы
  инлайновым SVG (векторно, ~0 КБ веса, чёткие на любом экране, не требуют сети);
- фирменные лого-локапы (петух + «aitas ukpf», знак «aitas» в подвале);
- типографика с табличными цифрами, единая сетка карточек и панелей.

## Анимация и интерактив

- поштучное появление карточек и панелей (stagger), плавные переходы между разделами;
- анимированный счёт значений KPI + спарклайн-динамика с прорисовкой линии;
- «Поток контроля ТМЦ» с бегущими индикаторами и шкалами объёма;
- фирменные настройки Chart.js: скруглённые столбцы, градиентная заливка тренда,
  подпись в центре кольцевой диаграммы, единые тултипы;
- карточка записи: сравнение «по документу / факт» с полосой расхождения, флаги
  нарушений, переход к соседним записям стрелками `←` `→`, `Esc` — закрыть, печать;
- тосты вместо `alert()`, drag & drop файла в любое место окна, ripple на кнопках;
- полностью учитывается `prefers-reduced-motion`; есть адаптив и стили печати.

## Данные

**Демо-режим.** При открытии показываются детерминированные демо-данные за 30 дней.

**Свои данные.** Кнопка «Загрузить Excel» либо перетаскивание файла в окно.
Ожидаемая структура книги:

- лист с «Внешний» в названии — шапка со столбцом `№ Акт Входного Контроля`;
- лист с «Внутренний» в названии — шапка со столбцом `№ Накладной`;
- лист «Транспорт … Факт» — шапка со столбцом `Дата отбора` (лаб. контроль).

**Сводка смывов.** Кнопка «Загрузить сводку смывов» разбирает сырой xlsx потоково в
Web Worker (интерфейс не блокируется), оставляя только записи УКПФ.

**PEST Control.** Ввод по площадкам сохраняется в `localStorage` браузера,
импортируется и выгружается в Excel.

## Горячие клавиши

`1`–`5` — разделы, `/` — поиск по журналу, `←` `→` — соседние записи в карточке, `Esc` — закрыть.

# Ролик «Входной контроль внешнего периметра»

Дашборд ищет видео по пути `assets/external-flow.mp4` рядом с `dashboard.html`.

1. Скачайте mp4 из карточки генерации Higgsfield (или по прямой ссылке из чата).
2. Переименуйте в `external-flow.mp4`.
3. Положите в эту папку — рядом с `dashboard.html` должна получиться структура:

```
dashboard.html
assets/external-flow.mp4
```

4. Откройте `dashboard.html` — плеер включится сам.

Если файла нет, раздел показывает раскадровку из 7 сцен вместо плеера —
страница остаётся рабочей.

Параметры сгенерированного ролика: seedance 2.5, 5 с, 1280×720, 16:9, со звуком.
Полное ТЗ на ролик — в `report.html`, раздел 01.
